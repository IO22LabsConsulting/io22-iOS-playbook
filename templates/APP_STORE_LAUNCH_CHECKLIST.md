# App Store Launch Checklist

## Product Quality

- [ ] Core user journey works end-to-end
- [ ] No open P0 defects
- [ ] Crash-free sessions target met
- [ ] Tested on lowest supported iPhone model

## Privacy and Trust

- [ ] Privacy policy published and linked in app
- [ ] Terms and support links are live
- [ ] Data collection map reviewed
- [ ] Export and deletion flows validated
- [ ] Permission prompts explained in context

## App Store Assets

- [ ] App name and subtitle finalized
- [ ] Keywords finalized
- [ ] Description and release notes finalized
- [ ] Screenshots uploaded for required devices
- [ ] App icon and promotional assets approved

## Compliance

- [ ] App Store privacy questionnaire completed accurately
- [ ] Sensitive permissions justified clearly
- [ ] Third-party SDK list reviewed

## Operations

- [ ] Crash/performance monitoring enabled
- [ ] Support inbox ownership assigned
- [ ] Incident response owner assigned
- [ ] Rollback or hotfix process documented

## Launch Day

- [ ] Final build submitted
- [ ] Team launch checklist sign-off complete
- [ ] Post-launch monitoring windows scheduled
